# 開発

[README に戻る](../README.ja.md)

`make dist` は実行環境向けのバイナリと `LICENSE`、`THIRD_PARTY_NOTICES.md`、`licenses/` を `target/dist/` のアーカイブへまとめます。バイナリの配布時はこれらを一緒に配布してください。依存関係の更新後は `make licenses` で文書を再生成して内容を確認し、`make licenses-check` で現在のロックファイルとの一致を検証できます。ライセンス文書の生成・検証には Python 3.7 以上と Cargo が必要で、Cargo のキャッシュへ依存クレートをダウンロードする場合があります。一覧はデフォルト機能の通常／ビルド依存を全ターゲット分含み、開発専用・無効な任意依存は除外します。

## 履歴検索の計測

比較する各版を `make release` でビルドし、バイナリを別々の名前で保存します。Python 3.7 以上で次を実行してください。

```bash
mise exec -- python3 scripts/bench_history.py /tmp/zsh-turbo-before target/release/zsh-turbo > /tmp/history-bench.json
```

スクリプトは一時ディレクトリに合成した zsh 履歴を作り、設定・キャッシュ・状態の保存先を普段のシェルから分離します。CLI の起動、履歴の復元、順位付けを合わせた時間を測ります。ケースごとに各バイナリを3回ウォームアップし、交互に15回ずつ計測します。JSON には全計測値、中央値、標準偏差、入力サイズ、出力のハッシュを保存します。出力が異なれば比較を中止します。

入力は1,000件と10万件で、前方一致・部分一致・曖昧一致、一致なし、日本語を含む履歴を扱います。大きい入力は明示的な `--history-file` の検証用です。ディレクトリ別履歴には1,000件の上限があります。比較時はツールチェーンと依存関係のロックファイルをそろえてください。
